# About

Recipes are code-snippets that you can directly copy from this site into your plugin to get a good starting point or template for whatever you want to implement.  
Simply click the copy button in the top-right corner of any code-block to directly copy all content to your system clipboard.  

All of these recipes will work as-in, no need for extra configuration, except explicitly stated.
