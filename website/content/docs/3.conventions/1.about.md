# Conventions

To keep the entire framework and your plugin clean and structured, Vital follows some conventions that you need to be aware of before actually starting to code your plugin.  
These conventions not only define HOW you write your code, but also how you ACCESS specific Vital functionalities. You cannot go around these conventions.  

Please take a short moment to familiarize yourself with these conventions before you start your Vital development journey.
