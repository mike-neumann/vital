# Using a starter project (~5 minutes)

To quickly get started with a clean project template you can use our starter projects.  
These starters only contain a single main plugin file and the core module.  

You can use the following starter projects.  
Each download link will redirect you to [DownGit](https://downgit.github.io/#/home) to directly download the starter projects files from our [GitHub repository](https://github.com/mike-neumann/vital).
- [Spigot](https://downgit.github.io/#/home?url=https://github.com/mike-neumann/vital/tree/main/initializer/starter-spigotr)
- [Paper](https://downgit.github.io/#/home?url=https://github.com/mike-neumann/vital/tree/main/initializer/starter-paper)
- [Bungee](https://downgit.github.io/#/home?url=https://github.com/mike-neumann/vital/tree/main/initializer/starter-bungee)

Please follow these steps to get your project up-and-running.
1. Download and extract starter project to your preferred location.
2. Open the extracted directory in your favorite IDE (Or not if you're crazy).
3. Go into your projects directory and execute `./gradlew build` in terminal, or via IDE run configuration.
4. Move built project file (`build/libs/project.jar`) into your server's `plugins/` directory and restart or reload your server.

## Troubleshooting

If you are experiencing any problems during project initialization, like `./gradlew build`, etc.  
Please make sure you are running the correct JDK (`24`) and retry.  
If you are still running into problems, a `./gradlew clean` or cleaning your Gradle cache files under `~/.gradle/caches/` might help.  
If not, please create an issue on [GitHub](https://github.com/mike-neumann/vital/issues/new).
