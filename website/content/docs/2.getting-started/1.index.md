# About

Vital is the world's first true fullstack, multi-platform Minecraft plugin framework built to make your plugin developers happy with features they always wanted but could never have.  
It provides extensive features ranging from small ones like creating dynamic scoreboards, to even massive ones like an advanced command system and even a game framework to develop your own games.  

Vital is a full-feature framework bringing enterprise-grade technologies to your Minecraft plugin.  
With it, you can finally create plugins that are on the same professional level as real world applications.  

## Why?

If you are a plugin developer or have written a plugin before you probably ran into the following annoyances:  

- Forgetting to register a command.
- Forgetting to register a listener.
- Writing endless if-statements for your commands to handle arguments.
- Having to manually write tab-completions for your commands.
- Creating dynamic scoreboards and bloating a single file with endless recreation methods...
- Creating holograms and manually needing to spawn markers...
- Randomly scheduling tasks anywhere in your code and later wondering where that piece of code even is now.
- Creating minigames and bloating your entire event handling system with guard-if-statements to check if the event should be handled or not.
- Manually maintaining your `plugin.yml`.
- ... the list goes on...

Most developers just deal with these annoyances, few developers build their own solutions, even fewer developers share their solutions with others.  
For some of these issues there are public solutions that you can use, but there currently isn't a solution that covers **ALL** of these problems.  

This is Vital.

Vital is the ultimate Minecraft plugin framework built to handle all of this (and more).  
It not only covers the problems mentioned above, it completely revolutionizes the way you create plugins.  

## Great! How do I start?

Now that you're convinced you can create your very first Vital plugin in under 5 minutes using the installation guide.

We recommend using a [starter project](/docs/getting-started/starter), but you can also use the [initializer](/docs/getting-started/initializer) (currently not available on the web),  
or just [configure the project manually](/docs/getting-started/manual) (Not that difficult but takes a couple of minutes longer).

Once your project is set up, choose a [module](/docs/modules/about) you like and start building!
