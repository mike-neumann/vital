# About

To keep everything neatly structured and also to keep your plugin JAR size small, Vital is structured into multiple modules that all do specific things.  
Each module adds its own different functionality to your plugin, like commands, inventories, holograms, configs, minigames, etc.  

> The core module is required for all other modules because it contains the main functionality of Vital.

---

To make your life as easy as possible, Vital provides its own Gradle plugin so JAR bundling and dependency version management is automatically handled for you.  
To add a module to your plugin, simply add it as an implementation dependency without specifying a version.
```kotlin
// build.gradle.kts
plugins {
  id("me.vitalframework.vital-gradle-plugin") version "1.0.0"
}

dependencies {
  implementation("me.vitalframework:vital-commands")
  implementation("me.vitalframework:vital-configs")
  implementation("me.vitalframework:vital-holograms")
  // ...
}
```
