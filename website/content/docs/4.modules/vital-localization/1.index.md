# About

This module adds localization support to your plugin using the Spring message bundles system.

## Platform compatability

| Platform   | Compatible | Notes                                                                                                   |
|:-----------|:-----------|:--------------------------------------------------------------------------------------------------------|
| Spigot     | ✅          | This platform is fully supported. Use platform-specific implementation subclasses (`SomeClass.Spigot`). |
| Paper      | ✅          | This platform is fully supported. Use platform-specific implementation subclasses (`SomeClass.Spigot`). |
| BungeeCord | ✅          | This platform is fully supported. Use platform-specific implementation subclasses (`SomeClass.Bungee`). |
