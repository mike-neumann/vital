# About

This module allows you to create holograms for your server.  
You can create two types of holograms: global holograms and player holograms.  

Global holograms are used when you want to display global information **that is the same for all players on the server**.  
You **cannot display translated text or data with global holograms**.  

Player holograms are bound to a specific player and can therefore be used to display data that is unique to a single player.  
This type of hologram can be used to display stats, kills, and also translated text or other data.  

Please refer to the respective documentation for both holograms on the left navigation.
