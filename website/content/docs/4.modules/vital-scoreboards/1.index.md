# About

With this module you can finally create dynamic scoreboards without having to pollute your code base with huge scoreboard bloat and helper classes.  
Write dynamic scoreboards even in a single line of code!  

This module supports two types of scoreboard, global scoreboard and player scoreboards.  
Global scoreboards, like the name implies will show global data and text that is **THE SAME FOR ALL PLAYERS ON THE SERVER**. You can't show translated text / data with this scoreboard.  

You can also create player scoreboards that are specifically designed to show data that may be unique across multiple players.  
With player scoreboards, you can create scoreboards that show translated text and show data specifically tied to a single player, like kills, stats, etc.  

Please refer to the respective documentation for both scoreboards on the left navigation.
