# About

This module can be added to include a health check statistics task into your plugin.  
It will check server health by running a lightweight scheduled task that will probe the server's TPS and report fluctioations.  

TPS warnings will automatically be displayed in the console but can also be viewed using the built-in `/stats tps` command.  
Command senders will need the permission `dev.vitalframework.command.vital-stats`. to execute this command.  

## Configuration

You can also configure this module using your application configuration (`application.yaml`, `application.properties`, etc.) to only reports TPS warnings if a specific threshold is surpassed.  
```yaml [application.yaml]
vital:
  statistics:
    min-tps: 16
    max-task-inactive-tolerance: 250
    max-tps-task-cache: 16
```

The configuration shown above is the default configuration.
