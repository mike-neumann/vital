# About

With this module you can finally create custom server commands that are actually maintainable and readable.  
Use Vital's advanced command system to create annotation-driven commands with automatic tab-completion and exception handling mechanisms that actually make sense.  

Every command will be a class that extends `VitalCommand.Spigot` and is annotated with `VitalCommand.Info`.  
A command can have n-number of arg handlers, each arg handler is essentially a method that is executed, when the command is executed with the configured argument.  

Please refer to the respective documentation on the left navigation.
