# About

This module can be used to add a simple CloudNET bridge API wrapper to your plugin.  
The default CloudNET bridge module API is pretty annoying to use, this module will provide you with a much simpler API.  

Please check out the Javadoc for `VitalCloudNet4Bridge` for more information.
