# Listeners

Use Vital listeners to automatically register your listener when your plugin starts up.  
Essentially, Vital listeners are just normal listeners but are exposed as a Spring bean.  

```java [MyListener.java]
@Listener
public class MyListener extends VitalListener.Spigot {
  @EventHandler
  public void onPlayerJoin(PlayerJoinEvent e) {
    // ...
  }
}
```

And that's it...  
No more configuration required, when your plugin starts up, Vital will detect your listener and automatically register it.
