# Configuration

The `vital-core` module can be configured using your application configuration (`application.yaml`, `application.properties`, etc.) in your project's `src/main/resources` location.  
Currently, this module only contains configurations for bStats.  

```yaml [src/main/resources/application.yaml]
vital:
  core:
    bstats:
      enabled: true
      plugin-id: 1234567890
```

You can freely enable or disable bStats metrics for your plugin.  
By default, Vital sends its own metrics to bStats, to configure your own plugin, please visit [bstats.org](https://bstats.org).  

> When you disable bStats, it will disable metrics for Vital, as well as metrics for your own plugin.
