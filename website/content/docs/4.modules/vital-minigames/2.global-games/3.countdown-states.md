# Countdown states

You can also create global states that directly act as a countdown.  
This is especially useful to create "Starting" states to transition into the actual "Running" state.  

Global countdown states are essentially normal global states, if you are not familiar with how normal global states work, please check out the documentation for [global states](/docs/modules/vital-minigames/global-games/states) before continuing here.  
Also, instanced countdown states are basically countdown tasks from the `vital-tasks` module, please make yourself familiar with how to use these [countdowns tasks](/docs/modules/vital-tasks/countdown-tasks) before you continue here.

---

Every global countdown state will be a class that extends `VitalGlobalCountdownMinigameState`.  
```java
@GlobalMinigameState
@VitalCountdownTask.Info(internal = 1_000, countdown = 1_000)
public class MyGlobalCountdownState extends VitalGlobalCountdownMinigameState {
  public MyGlobalCountdownState(JavaPlugin plugin) {
    super(plugin);
  }
}
```
