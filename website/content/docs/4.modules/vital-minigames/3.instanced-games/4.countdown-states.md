# Countdown states

You can also create states that directly act as a countdown.  
This is especially useful to create "Starting" states to transition into the actual "Running" state.  

Countdown states are essentially normal instanced states, if you are not familiar with how normal instanced states work, please check out the documentation for [instanced states](/docs/modules/vital-minigames/instanced-games/states) before continuing here.  
Also, instanced countdown states are basically countdown tasks from the `vital-tasks` module, please make yourself familiar with how to use these [countdowns tasks](/docs/modules/vital-tasks/countdown-tasks) before you continue here.

---

Every instanced countdown state will be a class that extends `VitalMinigameInstanceCountdownState<T extends VitalMinigameInstance>`.  
```java [MyInstanceCountdownState.java]
@VitalCountdownTask.Info(internal = 1_000, countdown = 1_000)
public class MyInstanceCountdownState extends VitalMinigameInstanceCountdownState<MyInstance> {
  public MyInstanceCountdownState(MyInstance myInstance) {
    super(myInstance);
  }
}
```

All lifecycles from [instanced states](/docs/modules/vital-minigames/instanced-games/states) and [countdown tasks](/docs/modules/vital-tasks/countdown-tasks).
