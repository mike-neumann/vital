# About

Instanced games allow you to host multiple games (even of different types) on the same server without having to worry about isolation or game logic leaking into any of your other running games.  
This is perfect for servers who want to keep server-count low and still host multiple games.  

If you are looking for hosting multiple servers where each server is only one running game, check out [global games](/docs/modules/vital-minigames/global-games/about).
