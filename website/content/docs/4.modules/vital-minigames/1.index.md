# About

Using this module, you can finally create true isolated minigames using proper game development strategies.  
You can create two types of games, a [global game](/docs/modules/vital-minigames/global-games/about) where the entire server is basically one running game, and [instanced games](/docs/modules/vital-minigames/instanced-games/about) where you can host as many games on the same server as you like.  

Both have their pros and cons.  

## Global games

Simpler, requires less configuration and can be managed as normal Spring beans like all of your other Vital components (commands, listeners, etc.).  
When you use global games, you can freely inject beans from A to B without any hassle.

## Instanced games

More complex, but allows for players to play games without having to connect to another server.  
Better if you are currently not able to host a single extra server just to host one round of a game.
