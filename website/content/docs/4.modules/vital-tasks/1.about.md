# About

With this module, you can create repeatable tasks and countdown tasks that run directly on your server's scheduler (`Bukkit.getScheduler()`, `ProxyServer.getInstance().getScheduler()`, etc.).  
This allows you to directly call synchronous server APIs that MUST run on the server's main thread in a structured manner.  

Please refer to the respective documentation for both tasks on the left navigation.
