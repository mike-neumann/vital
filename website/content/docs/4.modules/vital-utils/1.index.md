# About

The `vital-utils` module contains utilities for various use cases:
- Adventure component conversion (MiniMessage, BungeeComponents, etc.)
- Creating chat buttons, etc.
- Creating censored text regex
- Censoring texts based on regex
- Broadcast actions in a single line
- Broadcast titles
- Broadcast potion effects
- Broadcast sounds
- Broadcast action bar
- Cleaning world game rules (for minigames etc.)
- Teleport players with effects
- Loop sounds
- etc.

Please check out the Javadoc for `VitalUtils` for more information.

> This module can also be used outside a Vital plugin, just add it as a dependency and you're good to go!
