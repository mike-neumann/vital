# About

Using this module, you can easily add interactable items to your plugin without having to worry about implementing your own event handlers, etc.

## Platform compatability

| Platform   | Compatible | Notes                               |
|:-----------|:-----------|:------------------------------------|
| Spigot     | ✅          | This platform is fully supported.   |
| Paper      | ✅          | This platform is fully supported.   |
| BungeeCord | ❌          | This platform is **not** supported. |
