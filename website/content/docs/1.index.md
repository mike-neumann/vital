# Welcome to the Vital docs

This is where your Vital development journey begins.  
These docs will help guide you to your first ever Vital plugin and to all other components that you can use to create your plugins.  

So lets get started!  
First, create your very first Vital plugin, we recommend using a [starter project](/docs/getting-started/starter), but you can also use the [initializer](/docs/getting-started/initializer) (currently not available on the web),  
or just [configure the project manually](/docs/getting-started/manual) (Not that difficult but takes a couple of minutes longer).  

Once your project is set up, choose a [module](/docs/modules/about) you like and start building!
