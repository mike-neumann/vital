# vital-core

This module contains the core components and functionality of the Vital-Framework.  

This module must be used in combination with `vital-core-processor`.  
Make sure you add the `vital-core-processor` module as an annotation processor, 
otherwise Vital will not automatically generate the `plugin.yml` for you.

To create a plugin with Vital, this is all you need.  
You might want to check out some of the Vital-Official modules to expand functionality though.
