# vital-localization

This module can be used to add Vital's i18n (localization / internationalization) system to your plugin.  
It provides the means of sending translated messages, or getting translated text using Spring's i18n system.  

Players may hold a locale / language that when changed, will deliver language-specific messages.  

When using this module in combination with `vital-items`, the content / translated item names will automatically be updated, when a player's locale is changed.
